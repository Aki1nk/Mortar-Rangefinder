# PUBG 迫击炮测距工具 MVP 设计

## 目标

优先交付个人可用的 Windows WPF 工具：在多显示器 PUBG 地图上手动标定，使用可配置热键或鼠标点击记录炮位和目标，显示距离、方位角和射程状态。

## 保留功能

- Per-Monitor V2 DPI 与多显示器物理像素坐标。
- 两点手动标定，支持 100m、500m、1000m 和自定义距离。
- 热键记录炮位、目标、进入点击选点、开始标定、清除、显示/隐藏、切换穿透和取消。
- 设置窗口，可修改并保存热键及射程、透明度等基础设置。
- 顶置横条悬浮窗；正常状态鼠标穿透，选点时临时捕获。
- 距离、北向为 0° 的顺时针方位角，以及 121–700m 默认射程判断。

## 暂缓功能

- 托盘图标与关闭后驻留。
- 单实例唤醒。
- 测量历史及其界面。
- 自包含单文件发布、复杂故障恢复与全量审查流程。

## 技术边界

- 不读取游戏进程或内存，不注入，不截图识别，不自动控制鼠标，不访问网络。
- 所有坐标都使用 Windows 虚拟桌面的物理像素坐标。
- 初版面向个人当前的显示器环境；显示器、分辨率或 DPI 改变后要求重新标定。

## 验收

1. 双屏环境中可在任一屏完成标定及炮位/目标选点。
2. F6/F7 与点击选点对同一坐标得到相同结果。
3. 设置窗口可改动并保存热键，重启后恢复。
4. Esc 能退出选点并恢复鼠标穿透。
5. 应用构建成功，核心及新增功能测试通过，可手动启动验证。
