# PUBG 迫击炮测距工具设计规格

## 1. 项目目标

构建一个面向 Windows 版 PUBG 的轻量桌面悬浮工具。玩家打开游戏地图后，通过鼠标点击或热键记录标定点、迫击炮位置和目标位置；工具依据人工标定得到的“米/像素”比例，实时计算距离、方位角、像素差和射程状态。

工具必须保持人工辅助边界：不读取游戏进程或内存、不注入游戏、不识别画面、不自动移动鼠标、不执行瞄准或开火操作。

## 2. 技术方案

- 平台：Windows 10/11
- 技术栈：C#、WPF、.NET 10 LTS
- 发布形式：自包含、单文件 Windows 可执行程序
- 权限：普通用户权限，不要求管理员权限
- 网络：完全离线，不进行联网、上传或遥测
- 实例策略：仅允许一个程序实例，重复启动时唤醒已有实例

选择 WPF 的主要原因是透明置顶窗口、鼠标穿透、系统托盘、全局热键和 Windows 屏幕坐标处理均可直接通过原生桌面能力实现，运行开销低，适合游戏期间持续悬浮。

## 3. 核心使用流程

### 3.1 启动

1. 启动程序后显示紧凑横条悬浮窗。
2. 悬浮窗默认置顶、可拖动、启用鼠标穿透。
3. 如果没有有效标定，横条显示“未标定”，测量操作不可产生最终距离。
4. 用户通过“切换鼠标穿透”热键或系统托盘临时解锁窗口，完成拖动、展开面板或点击命令后可再次开启穿透。

### 3.2 手动标定

1. 用户通过悬浮窗命令或可配置热键进入标定模式。
2. 用户依次选择两个地图点，可使用以下任一输入方式：
   - 进入捕获模式后直接左键点击；
   - 将鼠标移动到点位后按记录热键。
3. 用户选择 `100 米`、`500 米`、`1000 米`，或输入任意大于零的自定义距离。
4. 工具根据两点像素距离计算“米/像素”比例。
5. 工具保存比例、已知距离、两个标定点、显示器标识、分辨率、DPI 信息和标定时间。
6. 地图缩放发生变化后，用户必须重新标定。工具不尝试自动判断游戏地图缩放级别。

### 3.3 测量

测量支持两种并存的输入方式：

#### 热键模式

1. 鼠标移动到迫击炮位置，按“记录炮位”热键。
2. 鼠标移动到目标位置，按“记录目标”热键。
3. 第二个点记录后立即计算并显示结果。

#### 点击模式

1. 按“进入点击选点模式”热键或点击悬浮窗命令。
2. 全屏透明选择层暂时关闭鼠标穿透。
3. 用户依次左键点击迫击炮位置和目标位置。
4. 第二次点击后完成计算，选择层恢复鼠标穿透并自动隐藏。

#### 通用操作

- “取消当前操作”按键取消当前标定或测量步骤，默认使用 `Esc`，仅在选择层处于活动状态时生效。
- 用户可清除当前测量并重新选择炮位或目标。
- 所有动作热键均可修改并永久保存。

## 4. 计算规则

设标定点为 `C1(x1, y1)` 和 `C2(x2, y2)`，已知实际距离为 `knownMeters`：

```text
calibrationPixels = sqrt((x2 - x1)^2 + (y2 - y1)^2)
metersPerPixel = knownMeters / calibrationPixels
```

设迫击炮位置为 `M(mx, my)`，目标位置为 `T(tx, ty)`：

```text
deltaX = tx - mx
deltaY = ty - my
targetPixels = sqrt(deltaX^2 + deltaY^2)
distanceMeters = targetPixels * metersPerPixel
```

屏幕正上方视为北方 `0°`，方位角顺时针增加：

```text
bearingDegrees = normalizeDegrees(atan2(deltaX, -deltaY))
```

其中右方为 `90°`、下方为 `180°`、左方为 `270°`。

显示规则：

- 距离默认四舍五入到整数米。
- 方位角默认四舍五入到整数度，并格式化为三位数字，例如 `072°`。
- 原始浮点结果保留在内存中，避免多次舍入造成误差。
- 射程状态根据设置中的最小和最大有效射程判断。
- 初始射程默认值为 `121 米` 至 `700 米`，用户可修改并保存。

## 5. 显示器与坐标规则

- 所有输入点统一转换为 Windows 虚拟桌面的物理像素坐标。
- 程序启用 Per-Monitor V2 DPI 感知，避免 WPF 逻辑坐标与物理像素混用。
- 支持多显示器和负坐标显示器布局。
- 标定绑定创建标定时所在的显示器、分辨率和 DPI。
- 如果显示器、分辨率或 DPI 与标定记录不一致，标定自动失效并提示重新标定。
- 如果用户仅改变了游戏地图缩放，程序无法可靠自动检测，因此由用户主动重新标定。

## 6. 界面设计

### 6.1 紧凑横条

主界面采用用户确认的紧凑横条布局，默认显示：

- 标定状态；
- 目标距离大字；
- 方位角；
- 射程状态；
- 当前操作提示；
- 关键热键提示。

横条要求：

- 无边框、置顶、半透明；
- 可拖动到任意显示器位置；
- 可调整透明度和字体大小；
- 默认鼠标穿透；
- 支持热键显示或隐藏；
- 保存最后位置，并在显示器布局变化后自动修正到可见区域。

### 6.2 展开面板

紧凑横条可展开一个小型详情面板，显示：

- 水平像素差；
- 垂直像素差；
- 当前米/像素比例；
- 标定时间与标定距离；
- 最近测量历史；
- 重新标定、清除测量和打开设置的快捷命令。

### 6.3 选点视觉反馈

- 标定点：蓝色标记；
- 迫击炮位置：绿色标记；
- 目标位置：红色标记；
- 两点连线：细虚线；
- 当前鼠标位置：轻量十字准星；
- 完成测量后标记短暂保留，然后自动隐藏；
- 正常状态下不显示全屏选择层，也不阻挡游戏输入。

### 6.4 系统托盘

关闭主窗口时默认缩小到系统托盘。托盘菜单提供：

- 显示/隐藏悬浮窗；
- 开启测量；
- 重新标定；
- 打开设置；
- 退出程序。

## 7. 热键系统

以下动作均拥有独立、可配置的全局热键：

- 记录炮位；
- 记录目标；
- 进入点击选点模式；
- 开始重新标定；
- 清除当前测量；
- 显示/隐藏悬浮窗；
- 开启/关闭鼠标穿透。
- 取消当前操作；该按键只在标定或选点状态下处理，不注册为常驻全局热键。

热键要求：

- 首次运行提供以下默认绑定：
  - `F6`：记录炮位；
  - `F7`：记录目标；
  - `F8`：进入点击选点模式；
  - `F9`：开始重新标定；
  - `F10`：清除当前测量；
  - `F11`：显示或隐藏悬浮窗；
  - `Ctrl+F11`：开启或关闭鼠标穿透；
  - `Esc`：取消当前操作，仅在选择层活动期间生效；
- 用户修改后立即尝试注册；
- 检测同一配置内的重复绑定；
- 系统注册失败时保留旧绑定并给出明确提示；
- 设置保存后在下次启动时恢复；
- 不使用低级键盘钩子记录普通键盘输入，仅处理已配置动作。

## 8. 设置与历史数据

使用本地 JSON 文件保存数据，目录位于当前用户的应用数据目录。

### 设置内容

- 热键绑定；
- 最小和最大有效射程；
- 悬浮窗位置、透明度和字体大小；
- 鼠标穿透默认状态；
- 历史记录数量上限；
- 标记保留时长；
- 最近一次有效标定。

### 历史记录

每条记录包含：

- 测量时间；
- 距离；
- 方位角；
- 水平和垂直像素差；
- 测量时使用的米/像素比例；
- 射程状态。

默认最多保留最近 20 条，用户可修改上限或清空历史。

### 文件可靠性

- 保存时先写入临时文件，再以替换方式更新正式文件；
- 配置损坏时备份损坏文件并恢复默认设置；
- 未知字段应被忽略，以支持后续版本升级；
- 数据文件不包含游戏截图、进程信息或个人信息。

## 9. 模块划分

- `OverlayWindow`：紧凑横条和展开面板。
- `SelectionOverlayManager`：按显示器创建透明选择窗口，统一管理全虚拟桌面的选点、准星、标记和连线。
- `GlobalHotkeyService`：注册、注销和验证全局热键。
- `PointerCaptureService`：读取物理屏幕鼠标坐标并管理点击捕获状态。
- `CalibrationService`：创建、验证和失效标定。
- `MeasurementService`：计算距离、方位角、像素差和射程状态。
- `DisplayTopologyService`：显示器、虚拟桌面、DPI 与坐标转换。
- `SettingsService`：读取、验证和安全保存设置。
- `HistoryService`：保存和裁剪测量历史。
- `SingleInstanceService`：阻止多实例并唤醒现有窗口。
- `TrayIconService`：系统托盘生命周期和菜单。

业务计算模块不依赖 WPF 窗口，便于独立测试。

## 10. 状态与错误处理

程序主要状态包括：

- 未标定；
- 已标定、等待测量；
- 等待第一个标定点；
- 等待第二个标定点；
- 等待已知距离；
- 等待炮位；
- 等待目标；
- 显示结果；
- 操作已取消；
- 热键注册失败；
- 标定因显示器变化失效。

错误处理原则：

- 不在游戏过程中弹出阻塞式错误窗口；
- 普通问题显示在悬浮横条或设置页中；
- 任何失败都应恢复到可重新操作的稳定状态；
- 无效标定距离、两个相同点、未标定测量等输入必须被拒绝；
- 退出选择模式时必须恢复鼠标穿透，避免透明层锁住桌面操作。

## 11. 明确不做的功能

第一版不包含：

- 游戏进程读取、内存读取或 DLL 注入；
- 自动截图、地图识别或缩放识别；
- 自动移动鼠标、自动瞄准或自动开火；
- 基于地形高度、飞行时间或落点散布的弹道修正；
- 地图资源下载或在线账户；
- 云端同步、联网更新和遥测；
- 游戏内嵌覆盖接口或显卡覆盖层注入。

## 12. 验收标准

第一版完成时应满足：

1. 用户能够用任意已知距离完成两点标定。
2. 用户能够使用热键或鼠标点击两种方式记录炮位和目标。
3. 对相同输入点，两种输入方式产生一致的距离和方位结果。
4. 距离、方位角、像素差和射程状态正确显示。
5. 所有动作热键均可修改、验证、保存和恢复。
6. 正常状态下悬浮窗不阻挡游戏鼠标操作。
7. 点击选点结束或取消后，透明选择层不会继续拦截输入。
8. 分辨率、显示器或 DPI 变化后，旧标定自动失效。
9. 设置和最近 20 条历史在程序重启后保留。
10. 程序无需管理员权限或额外安装 .NET 即可运行。
11. 程序不访问游戏进程、不读取内存、不注入游戏、不访问网络。
